# Prompts para el arte conceptual (ChatGPT / generador de imágenes)

Cómo usarlos:
- Los prompts van **en inglés**: el generador de imágenes los entiende mejor. Puedes escribirle
  a ChatGPT en español y pegar el prompt en inglés.
- **Pocas cosas por imagen (12, en cuadrícula de 4x3)**: con más, las dibuja diminutas o se
  inventa la mitad.
- **Números en lugar de nombres**: los textos le salen mal. Cada casilla lleva un número y
  aquí abajo está la lista de qué es cada número.
- Primero el **prompt de estilo** (una sola vez). Después, cada hoja en la **misma
  conversación**, empezando por "Same style as before".
- Si una hoja sale mal: "Redo it. Keep exactly 12 items in a 4x3 grid, one per cell, numbered,
  nothing else in the image."

---

## 0. Prompt de estilo (pegar primero)

```
I'm making a voxel survival game set on a tropical island after a shipwreck. I need concept art
sheets of game assets. The art style for ALL images in this conversation:

- Voxel art like Cube World and Hytale: objects built from small cubes, chunky and cute, with
  slightly rounded / beveled silhouettes. NOT Minecraft: no noisy pixel textures, no flat
  16x16 pixel faces.
- Each cube face is a FLAT solid color with soft hand-painted shading: a lighter top, mid-tone
  sides, darker bottom. Clean, readable, low-poly look.
- Warm, saturated, cheerful palette: golden sand, bright leaf greens, turquoise water, warm
  brown wood, blue-grey stone.
- Soft sunny daylight from the top-left, small soft shadow under each object.
- Isometric 3/4 view (camera looking down at about 30 degrees), every object seen from the
  same angle and at a similar size.
- Plain light beige background. No scenery, no characters, no text except the numbers I ask
  for.

Reply "OK" and wait for my first sheet.
```
